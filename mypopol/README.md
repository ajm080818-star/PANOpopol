# 포트폴리오 수정 안내

이 사이트는 HTML, CSS, JavaScript만 사용합니다. `index.html`을 브라우저에서 열면 확인할 수 있습니다.

## 내 정보로 바꾸기

- `index.html`: 이름, 한 줄 소개, 자기소개 문장, 이메일 주소를 수정합니다. 이메일은 화면의 주소와 `mailto:` 링크 양쪽에 입력합니다.
- `script.js`: 파일 맨 위 `PROJECTS` 목록의 작품명, 실제 담당 범위, 사용 도구, 제작 기간, 설명을 수정합니다.
- 작품 파일: `assets` 폴더를 만들고 GIF/MP4 파일을 넣은 뒤 `script.js`의 `media` 경로를 파일명과 일치시킵니다. MP4는 `.mp4`, GIF는 `.gif` 확장자를 사용하면 자동으로 재생기 또는 이미지로 표시됩니다.
- 대표 비주얼: 현재 첫 화면은 CSS로 그린 임시 일러스트입니다. `index.html`의 `.hero-art` 안을 본인의 `<video>` 또는 `<img>`로 교체하고 `style.css`에서 크기와 `object-fit`을 조정합니다.
- 도구 아이콘은 임시 문자 배지입니다. 정식 로고를 사용하려면 사용 권한이 있는 로고 이미지로 교체하세요.

## 컬러

`style.css` 맨 위 `:root`에 색상 변수가 모여 있습니다. `--cloud`는 2026 팬톤 올해의 컬러인 PANTONE 11-4201 Cloud Dancer를 참고한 화면 바탕색입니다. 팬톤이 단일 올해의 컬러와 별도 조화 팔레트를 소개하므로, 블루·라일락은 이 포트폴리오를 위한 보조색 해석입니다.

작품 제목, 설명, 이메일, 제작 기간은 모두 교체용 임시 정보입니다. 실제 경력이나 작품 정보처럼 오해되지 않도록 표시해 두었습니다.
